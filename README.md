These are my dotfiles.

### Setup (new machine)

- Install iTerm and chose the dark background color preset for the default
  profile
- Install homebrew
- Install vim-plug
- Authenticate with Github and clone the repo

Then:

```
./bin/install
```

This also creates global LLM skills symlinks via a submodule.
